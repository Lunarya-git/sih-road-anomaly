# Documentation (`docs/`)

This directory is the central repository for project-wide documentation.

Here you will find:
- **Architecture Diagrams:** High-level visual representations of how the `ml/`, `app/`, and `backend/` components interact.
- **Problem Statement & Research:** Detailed write-ups on the SIH problem statement, our proposed solution, and related research on pothole detection algorithms.
- **Meeting Notes & Planning:** Logs of team discussions, sprint planning, and roadmap updates.
- **Design Specifications:** UI/UX wireframes for the app and heatmap dashboard.
